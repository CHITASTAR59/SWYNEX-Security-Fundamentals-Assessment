# Security Assessment Scope

## Project
SWYNEX Security Fundamentals Assessment

## Target
OWASP Juice Shop running locally.

## Target URL
http://127.0.0.1:3000

## Authorization
Testing is limited to the locally hosted training application.

## Assessment Objectives
- Review HTTP security headers.
- Examine application error handling.
- Review authentication and session security.
- Understand access-control risks.
- Document evidence and remediation recommendations.

## Exclusions
- External systems and third-party services.
- Denial-of-service testing.
- Testing outside the local lab.
- Accessing real users' data or credentials.
